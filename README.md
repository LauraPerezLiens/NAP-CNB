# NAP-CNB

NAP-CNB is a research project focused on the development of machine learning models for the identification and analysis of potential neoantigens.

The project integrates sequence processing, epitope classification, secondary structure prediction and neural network models for large-scale analysis of protein sequences.

## Project goals

- Detect potential epitopes in protein sequences
- Incorporate positional information of epitopes
- Use structural information such as secondary structure
- Train neural networks for epitope prediction
